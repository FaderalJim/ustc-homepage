安全登录 (使用 GitHub Token 替代传统密码)

因为纯静态网页没有后端数据库，为了在全网同步下保障绝对安全，**您的 GitHub Personal Access Token （具有 repo 权限）就是您最高级别的管理员“密码”**。
我们不会将 Token 明文存入代码（这是危险且会被 GitHub 强制封禁的）。
